# Сторінка новини SSS

Локальний адаптивний дизайн новини «Понад 1000 людей зареєструвалися для отримання грошової допомоги від УВКБ ООН» від 30.10.2026.

Відкрийте `index.html` або запустіть `npm start` і перейдіть на http://127.0.0.1:4175/. Залежності не потрібні. Для копіювання посилання браузер може вимагати localhost замість file://.

- `npm run build` — відтворення HTML із збереженого джерела.
- `npm run check` — перевірка незмінності заголовка й усіх семи абзаців, локальних ресурсів та синтаксису JS.
- `node scripts/browser-qa.mjs` — перевірка в установленому Chrome; сервер, профіль і звіт залишаються в цій папці.

## Дизайн

Хедер, повноекранне меню, футер, логотипи, шрифти Onest/Manrope та палітра перенесені з затвердженої сторінки проєкту SSS. Кремовий #FBF6EC, зелений #314C2C, жовтий #F6B93B. Новина має великий заголовок, оригінальне головне фото, бічну колонку проєкту, читабельну статтю та ручну фотокарусель.

Текст новини не переписувався: абзаци автоматично витягнуті з оригінального HTML і вставлені зі збереженням внутрішньої розмітки, посилань, пунктуації та нерозривного пробілу. Цитата зберігається в тому самому абзаці. Усі сім зображень — з цієї новини. Службові елементи навігації додані поза текстом статті.

Анімації: одноразова поява вступу, реакції кнопок, плавне перемикання каруселі мишею, індикатор прогресу читання. Автопрокручування немає. Підтримано prefers-reduced-motion. Основний текст і горизонтальна галерея доступні без JavaScript.
